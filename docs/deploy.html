Deploy the Live Translator App

The landing page is static (GitHub Pages). The interactive Streamlit app needs a one-time free deploy.

Why you saw a Streamlit login page: The app is not deployed yet, or it was set to Private in Streamlit Cloud. Visitors need a Public deployed app URL.

Option 1 — Render (recommended)

One-click deploy. Gives a public URL like https://multilingual-content-translator.onrender.com

Deploy on Render
  1. Sign up / log in to Render (free)
  2. Click Deploy — uses render.yaml from the repo
  3. Wait ~3 min for build, then open your app URL
  4. Optional: add OPENAI_API_KEY in Render Environment

Option 2 — Streamlit Community Cloud

Open Streamlit Cloud
  1. Sign in with GitHub (divyanshgupta)
  2. New app → Repository: multilingual-content-translator
  3. Main file: streamlit_app.py · Branch: main
  4. Visibility: Public (required — private apps ask visitors to log in)
  5. Deploy, then paste your *.streamlit.app URL into the landing page

Option 3 — Run locally

git clone https://github.com/divyanshgupta/multilingual-content-translator.git
cd multilingual-content-translator
uv sync
source .venv/bin/activate
python main.py ui
